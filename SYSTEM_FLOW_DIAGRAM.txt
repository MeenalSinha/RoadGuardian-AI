3. INFERENCE PIPELINE FLOW (Detailed Detection Process)
================================================================================

START: Single Image Detection
│
├─▶ [INPUT] Image Received
│   │
│   ├─▶ Source: Upload / File / Camera
│   ├─▶ Format: JPG / PNG / JPEG
│   └─▶ Size: Any (will be resized)
│
├─▶ [VALIDATE] Input Validation
│   │
│   ├─▶ Check if file exists
│   ├─▶ Check if valid image format
│   ├─▶ Check file size (< 10MB recommended)
│   │
│   ├─▶ Valid: Continue
│   └─▶ Invalid: Return error
│
├─▶ [LOAD] Read Image
│   │
│   ├─▶ cv2.imread(image_path)
│   ├─▶ Check if image loaded
│   └─▶ Get original dimensions (H x W)
│
├─▶ [PREPROCESS] Image Preprocessing
│   │
│   ├─▶ STEP 1: Format Conversion
│   │   └─▶ BGR → RGB (if needed)
│   │
│   ├─▶ STEP 2: Resize
│   │   └─▶ Original (HxW) → 640x640
│   │       └─▶ Maintain aspect ratio with padding
│   │
│   ├─▶ STEP 3: Normalize
│   │   └─▶ Pixel values: [0-255] → [0-1]
│   │
│   └─▶ STEP 4: Tensor Conversion
│       └─▶ numpy array → torch tensor
│           └─▶ Shape: [1, 3, 640, 640]
│
├─▶ [INFERENCE] Model Forward Pass
│   │
│   ├─▶ Load model to device (GPU/CPU)
│   │
│   ├─▶ BACKBONE: Feature Extraction
│   │   │
│   │   ├─▶ Input: [1, 3, 640, 640]
│   │   │
│   │   ├─▶ Conv layers + CSPNet blocks
│   │   │
│   │   └─▶ Multi-scale features:
│   │       ├─▶ P3: 80x80 (small objects)
│   │       ├─▶ P4: 40x40 (medium objects)
│   │       └─▶ P5: 20x20 (large objects)
│   │
│   ├─▶ NECK: Feature Pyramid
│   │   │
│   │   ├─▶ PANet fusion
│   │   ├─▶ Top-down pathway
│   │   ├─▶ Bottom-up pathway
│   │   │
│   │   └─▶ Enhanced features at all scales
│   │
│   ├─▶ HEAD: Detection
│   │   │
│   │   ├─▶ For each scale:
│   │   │   ├─▶ Predict bounding boxes
│   │   │   ├─▶ Predict class probabilities
│   │   │   └─▶ Predict confidence scores
│   │   │
│   │   └─▶ Raw predictions: [N, 85]
│   │       └─▶ [x, y, w, h, conf, cls0, cls1, cls2, ...]
│   │
│   └─▶ Inference time: ~2.4ms ⚡
│
├─▶ [POSTPROCESS] Non-Maximum Suppression (NMS)
│   │
│   ├─▶ STEP 1: Confidence Filtering
│   │   │
│   │   └─▶ Remove boxes with conf < threshold (0.15)
│   │       └─▶ Keep only confident detections
│   │
│   ├─▶ STEP 2: Class Assignment
│   │   │
│   │   └─▶ For each box:
│   │       ├─▶ Get max class probability
│   │       └─▶ Assign class ID (0/1/2)
│   │
│   ├─▶ STEP 3: Non-Maximum Suppression
│   │   │
│   │   └─▶ For each class:
│   │       │
│   │       ├─▶ Sort boxes by confidence
│   │       │
│   │       └─▶ Remove overlapping boxes:
│   │           │
│   │           ├─▶ Calculate IoU between boxes
│   │           ├─▶ If IoU > threshold (0.45):
│   │           │   └─▶ Keep highest confidence box
│   │           │       └─▶ Remove others
│   │           │
│   │           └─▶ Repeat for all boxes
│   │
│   ├─▶ STEP 4: Coordinate Transformation
│   │   │
│   │   └─▶ Convert from 640x640 to original size
│   │       └─▶ Scale coordinates back
│   │
│   └─▶ RESULT: Clean detections
│       └─▶ [N filtered boxes]
│
├─▶ [ANALYZE] Detection Analysis
│   │
│   ├─▶ For each detection:
│   │   │
│   │   ├─▶ Extract information:
│   │   │   ├─▶ Class: pothole/crack/damage
│   │   │   ├─▶ Confidence: 0.02-0.88
│   │   │   ├─▶ Bounding box: [x1,y1,x2,y2]
│   │   │   └─▶ Area: (x2-x1) × (y2-y1)
│   │   │
│   │   ├─▶ Calculate severity:
│   │   │   │
│   │   │   ├─▶ Factors:
│   │   │   │   ├─▶ Area (size of defect)
│   │   │   │   ├─▶ Confidence score
│   │   │   │   └─▶ Class type
│   │   │   │
│   │   │   └─▶ Severity classification:
│   │   │       ├─▶ Critical (0.8-1.0)
│   │   │       ├─▶ Moderate (0.5-0.8)
│   │   │       └─▶ Minor (0.0-0.5)
│   │   │
│   │   └─▶ Store detection data:
│   │       {
│   │         'class': 'pothole',
│   │         'confidence': 0.85,
│   │         'bbox': [100, 200, 300, 400],
│   │         'area': 40000,
│   │         'severity': 'Critical',
│   │         'severity_score': 0.9
│   │       }
│   │
│   ├─▶ Calculate statistics:
│   │   │
│   │   ├─▶ Total detections: N
│   │   ├─▶ Count by class:
│   │   │   ├─▶ Potholes: X
│   │   │   ├─▶ Cracks: Y
│   │   │   └─▶ Damage: Z
│   │   │
│   │   ├─▶ Confidence stats:
│   │   │   ├─▶ Mean: μ
│   │   │   ├─▶ Max: max
│   │   │   └─▶ Distribution: histogram
│   │   │
│   │   └─▶ Severity breakdown:
│   │       ├─▶ Critical: n1
│   │       ├─▶ Moderate: n2
│   │       └─▶ Minor: n3
│   │
│   └─▶ Calculate RCI:
│       │
│       └─▶ RCI = 100 - Σ(weight × severity × count)
│           │
│           ├─▶ Weights by class:
│           │   ├─▶ Pothole: 3.0
│           │   ├─▶ Crack: 1.0
│           │   └─▶ Damage: 2.0
│           │
│           └─▶ Result: 0-100 scale
│               ├─▶ 80-100: Good
│               ├─▶ 60-79: Fair
│               ├─▶ 40-59: Poor
│               └─▶ 0-39: Very Poor
│
├─▶ [VISUALIZE] Create Annotations
│   │
│   ├─▶ Copy original image
│   │
│   ├─▶ For each detection:
│   │   │
│   │   ├─▶ Draw bounding box:
│   │   │   ├─▶ Color by class
│   │   │   └─▶ Thickness: 3px
│   │   │
│   │   ├─▶ Draw label background:
│   │   │   └─▶ Filled rectangle above box
│   │   │
│   │   └─▶ Draw text label:
│   │       └─▶ "class | confidence%"
│   │
│   ├─▶ Add summary text (optional):
│   │   └─▶ "Found N defects | RCI: XX"
│   │
│   └─▶ Save annotated image
│
├─▶ [EXPORT] Prepare Results
│   │
│   ├─▶ JSON format:
│   │   {
│   │     "total_detections": N,
│   │     "rci_score": 75.5,
│   │     "classes": {
│   │       "pothole": X,
│   │       "crack": Y,
│   │       "damage": Z
│   │     },
│   │     "detections": [...]
│   │   }
│   │
│   ├─▶ CSV format:
│   │   class,confidence,x1,y1,x2,y2,severity
│   │   pothole,0.85,100,200,300,400,Critical
│   │   ...
│   │
│   └─▶ Images:
│       ├─▶ Annotated image (PNG)
│       └─▶ Heatmap (optional)
│
└─▶ [RETURN] Final Results
    │
    ├─▶ Annotated image
    ├─▶ Detection list
    ├─▶ Statistics
    ├─▶ RCI score
    └─▶ Exportable data
